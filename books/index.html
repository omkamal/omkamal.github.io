LLM Evaluation & Reliability Engineering

A Gentle Guide to Evals, Observability, and AgentOps for Developers Running AI Agents in Production

A gentle guide for developers who already call LLM APIs and now own what happens in production. Each chapter opens with a real incident, then explains the idea in plain English, shows the mechanism, and finishes with a small piece of Python. It covers how to evaluate LLM systems, how to observe them once they are live, and how to run AI agents reliably (AgentOps).

  • 20 chapters, each opening with a real production incident
  • Check-your-understanding questions and a hands-on deliverable in every chapter
  • Companion code on GitHub

A Gentle Introduction to Microservices for Python Developers

Designing, Building and Deploying Large Applications on AWS and Google Cloud

A friendly, step-by-step introduction for Python developers who have never designed a distributed system. You follow ShopFlow, an online shop that starts as a single Django monolith and is carefully split into FastAPI services deployed to AWS and Google Cloud. Every idea comes as a plain-English concept, an everyday analogy, a small example and a short piece of Python.

  • 72 original illustrations and diagrams
  • Worked examples and Python code in every chapter
  • FastAPI, Docker, AWS and Google Cloud

Advanced GraphRAG & Knowledge Agents

A Friendly, Illustrated Guide to Graph-Based Retrieval

What comes after vector search? This guide goes from the limits of flat vector RAG to the graph-based architectures that fix them, and the knowledge agents built on top. It covers six architectures in eight hands-on modules, including Microsoft GraphRAG, LightRAG and HippoRAG, and it is the written companion to the video course of the same name.

  • Why vector RAG fails on multi-hop questions
  • Graph construction, communities and DRIFT search
  • Six architectures across eight modules

Diagrams as Code

Exploring Mermaid, PlantUML, D2 and Generating Diagrams using AI LLMs

Documentation that behaves like code: version-controlled, reviewable and easy to regenerate. The book shows how to draw diagrams from plain text with Mermaid, PlantUML and D2, how lightweight markup such as AsciiDoc and Marpit turns documents into dynamic assets, and how to have AI language models generate the diagrams for you.

  • Mermaid, PlantUML and D2 side by side
  • Document-as-code with AsciiDoc and Marpit
  • Generating diagrams with AI LLMs
